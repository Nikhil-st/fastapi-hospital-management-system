Hospital Management System

A full-stack hospital management web application built with **Python, FastAPI, HTML, CSS, and JavaScript**.  
This project was developed from scratch to learn and implement FastAPI fundamentals, REST APIs, patient data management, and machine learning integration.

🚀 Features

- Patient management
- Patient details stored in JSON
- BMI calculation and health verdict
- REST API development using FastAPI
- API request and response handling
- Data validation using Pydantic
- Machine learning model integration
- Interactive web interface
- Swagger UI for API testing and documentation

🛠️ Tech Stack

- Backend: Python, FastAPI
- Frontend: HTML, CSS, JavaScript
- Data: JSON, CSV
- Machine Learning: Scikit-learn
- Data Processing: Pandas
- API Documentation: Swagger UI / OpenAPI
- Version Control:** Git & GitHub
